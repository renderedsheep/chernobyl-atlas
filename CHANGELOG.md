# Changelog

## 0.7 · November 2026
- Sheet margins in the style of a General Staff sheet: sheet number and name for the map centre, publisher and edition above the map; magnetic declination diagram and note, live scale (1:… and «в 1 сантиметре …») with a Soviet-style scale bar, datum, height system, contour interval and print code below.
- Kilometre grid in СК-42 / Gauss–Krüger with grid numbers on the frame; grid coordinates (X, Y, zone) in the status bar and in every object card.
- Colours taken from the printed sheet inks; base map tiles rebuilt on the sheet's paper tone.
- Drafting-style lettering (Jura) for short labels, tabs, grid numbers and data.
- Object cards with a fine double rule; lead photos mounted like prints with paper corners.
- Legend laid out like a Soviet legend booklet: one column, each symbol in a ruled box, Russian name with English beneath.
- New banner: condensed Oswald title with the English name beneath, a line drawing of unit 4 and its ventilation stack, a cell row (scale, sheets, editions, version) after the title block of Soviet technical drawings, an inked «Для служебного пользования» stamp and a faint printed grid. The old manuscript-style title font is gone.
- "Suggest a correction": links in every object card, a map-click popup ("suggest a site here") and a help section, opening pre-filled GitHub issue forms.
- Bilingual tab titles in the atlas and the editor.
- Sheet records carry the declination, convergence, compilation note and print code read from each sheet's margin.
